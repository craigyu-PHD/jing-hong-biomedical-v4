# 精鴻生醫 v11｜品牌形象網站樣板（給老闆審閱）

以 v10 為基礎，依老闆第五輪回饋再升級。公開網址不變：`https://craigyu-PHD.github.io/jing-hong-biomedical-v4/`。

## 本輪九項改造

1. **客服狗雙造型**：收合時蹲坐吐舌（會擺動），展開時站起搖尾；頭像同步，開合切換即換造型。拖曳、全螢幕、位置記憶保留。
2. **只留一條跑馬燈**：移除頁面中段第二跑馬燈，僅保留 topbar。
3. **公司沿革時間軸**：原跑馬燈位置改為六個時間點（2003／2008／2013／2018／2022／2026）的國際感時間軸，捲動進場＋進度線動畫；年份與事件皆標「示意，待公司確認」。
4. **數據可點擊**：2003／6／9／3 四張卡改為連結，分別導向沿革、人用產品線、寵物產品線、技術品質。
5. **商城與訂單分流**：新增 `shop.html` 購物商城（散戶全系列選購、加入購物車、數量增減、小計、結帳示範、本地記憶）；`order.html` 定位為批發商與大型會員。全站導覽與頁尾同步加入商城入口。
6. **下拉重設計**：284px 方塊小卡改為 216px 整齊單行清單（編號＋標題＋箭頭），留白收緊。
7. **合作洽詢換色**：深綠改暖陶珊瑚漸層，與其他 CTA 區分且更清楚。
8. **世界地圖修復**：改為多邊形大陸輪廓＋點陣＋台北出發弧線，地圖可見且不變形。
9. **立體貓咪視覺**：`bioCanvas` 由分子網絡改為線條＋節點構成的 3D 貓咪臉，置中不被照片遮擋；滑鼠移動時旋轉、耳朵／臉頰／尾巴開合幅度明顯加大。

## 客服機器人（預留功能）

- 收合：蹲坐吐舌拉布拉多；展開：站立搖尾；可拖曳、一鍵全螢幕／縮回，狀態記憶於 `localStorage`。
- 四個快速問題＋關鍵字回覆＋轉接真人；回覆皆為**示範文案**。串接：在 `script.js` 的 `replyChat()` 中把 `t('chat.a*')` 換成 API 呼叫，`chat.a4` 換成客服系統連結。

# 精鴻生醫 v7｜品牌形象網站樣板（給老闆審閱）

以 v6 為基礎，保留 Protera 案例色票（近黑 `#100D0C`、暖褐 `#554C40`、陶土 `#A75743`、鼠尾草 `#70807E`、苔綠 `#A19C65`）與暖白底，依老闆回饋再做六項升級：

1. 上方功能列表加入懸浮動畫下拉選單（滑鼠移入／鍵盤 focus／點擊 caret 皆可展開，內含向下功能選項）。
2. 客服机器人改為全身拉布拉多 SVG 形象，尾巴搖擺、耳朵抖動、呼吸、歪頭、眨眼動畫。
3. 首頁狗狗照片以 `object-position: 50% 14%` 保留頭部構圖。
4. 按鈕改為漸層、光暈掃光與微位移；頁尾「快速連結」改為二欄科技感卡片（編號＋箭頭）。
5. 導覽、分頁、篩選、訂單選單字體放大（nav 14px、一般按鈕 13.5px）。
6. `order.html` 新增「國際訂購」版面：國別／幣別切換、試算報價、國際配送與報關說明、英文單據與多語客服，含示範表單稿下載。

另依補充要求，在 hero 3D 分子動畫後方加入 flow 光帶與光暈流動（三團柔光＋兩條流動光帶），提升科技感與氛圍；`prefers-reduced-motion` 時自動關閉。

| `assets/` | 本機圖片素材 |

## 客服機器人（預留功能）

- 右下角浮動全身拉布拉多形象，漂浮＋搖尾＋耳朵抖動＋呼吸＋歪頭＋眨眼＋光暈動畫；對話視窗內亦有同款小頭像。
- 點擊開啟／關閉對話視窗；開關狀態記憶於 `localStorage`；`Esc` 可關閉。
- 四個快速問題：產品資訊、訂單查詢、合作洽詢、轉接真人；也可直接輸入關鍵字。
- 目前回覆為**示範文案**，已標註「未來可接入 API／客服系統」。串接方式：在 `script.js` 的 `replyChat()` 中，把 `t('chat.a*')` 換成 API 呼叫；轉真人則替換 `chat.a4` 為客服系統連結或 Webhook。
- 中英文切換時，標題、歡迎語、快速問題、示範回覆同步切換。

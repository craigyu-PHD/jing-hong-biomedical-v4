# 精鴻生醫 v4｜品牌形象網站樣板

給老闆審閱的設計提案。以 v3 為基礎升級：清爽淺色配色、緊湊版面、人用／ANUBIS 寵物保健分區、雙語切換、最新消息公佈欄、生技粒子動畫，以及重新設計的訂單系統入口。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 首頁：主視覺、最新消息、品牌理念、雙產品線、技術品質、實例、訂單入口、洽詢 |
| `cases.html` | 實例分享（分類篩選） |
| `order.html` | 訂單系統入口（會員登入、訂單查詢、流程、服務、FAQ） |
| `style.css` | 共用樣式與 RWD |
| `script.js` | 雙語字典、篩選、表單示範、hero 粒子動畫 |
| `assets/` | 本機圖片素材 |

## 本機預覽

```bash
python3 -m http.server 8765
# http://127.0.0.1:8765/index.html
```

直接雙擊 `index.html` 也可開啟；部分瀏覽器對本機檔案的下載示範會有限制，建議用上述伺服器。

## 部署

GitHub Pages 直接由 `main` 分支根目錄提供，無需建置程序。

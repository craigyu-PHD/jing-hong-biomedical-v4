## 客服機器人（預留功能）

- 收合：蹲坐吐舌拉布拉多；展開：站立搖尾；可拖曳、一鍵全螢幕／縮回，狀態記憶於 `localStorage`。
- 四個快速問題＋關鍵字回覆＋轉接真人＋高風險健康提問合規攔截；回覆皆為**示範文案**。串接：在 `script.js` 的 `replyChat()` 中把 `t('chat.a*')` 換成 API 呼叫，`chat.a4` 換成客服系統連結，並接入正式合規審查。

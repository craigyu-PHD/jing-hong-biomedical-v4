# 精鴻生醫 v8｜品牌形象網站樣板（給老闆審閱）

以 v7 為基礎，保留 Protera 案例色票與暖白底，針對老闆第二輪回饋再升級：

1. **拉布拉多完整顯示**：机器人 SVG 改留白 viewBox（`-6 4 132 136`）、氣泡放大至 88px（手機 78px），頭、耳、四肢皆不裁切；首頁照片改 `object-fit:cover; object-position:50% 0%` 保留頭部，並加模糊底圖避免留白。
2. **背景線條放大**：3D 分子半徑 `.40→.62`、節點與鍵結加粗、距離閾值放大，核心光暈更強。
3. **flow 更明顯**：三團柔光加大至 460–520px、透明度提高，光帶 3 條＋2 個流動光點，皆帶發光暈。
4. **字體更高級**：標題改 Noto Serif TC 襯線、內文／UI 改 Manrope＋Noto Sans TC，字距與行高重新調整。
5. **右上角功能視窗**：導覽最右新增「功能選單」按鈕，點開浮動玻璃視窗（六個快速連結＋雙語切換＋呼叫客服）；原有各分頁下拉也升級為 288px 標題式浮動視窗。
6. **整體質感與動畫**：hero 標題進場、眉題底線伸縮、下拉分層滑入、按鈕掃光、卡片懸停、footer 連結發光；`prefers-reduced-motion` 時全數關閉。
7. **頁尾快速連結**：由二欄卡片改為橫式膠囊排列（自動換行），與上方導覽語彙一致。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 首頁：主視覺、最新消息、品牌理念、雙產品線、技術品質、實例、訂單入口、洽詢 |

| `assets/` | 本機圖片素材 |

## 客服機器人（預留功能）

- 右下角浮動全身拉布拉多形象，漂浮＋搖尾＋耳朵抖動＋呼吸＋歪頭＋眨眼＋光暈動畫；對話視窗內亦有同款小頭像。
- 點擊開啟／關閉對話視窗；開關狀態記憶於 `localStorage`；`Esc` 可關閉。
- 四個快速問題：產品資訊、訂單查詢、合作洽詢、轉接真人；也可直接輸入關鍵字。
- 目前回覆為**示範文案**，已標註「未來可接入 API／客服系統」。串接方式：在 `script.js` 的 `replyChat()` 中，把 `t('chat.a*')` 換成 API 呼叫；轉真人則替換 `chat.a4` 為客服系統連結或 Webhook。
- 中英文切換時，標題、歡迎語、快速問題、示範回覆同步切換。

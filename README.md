## 本輪改造（v14）

1. **貓咪回歸線條＋節點**：移除 v13 的奶油色实心猫臉，恢復原始 28 節點／32 條線的線框貓；改為深淺分層的薄荷綠線、前后景節點發光、暖陶鬍鬚與鼻尖、眼睛高光，並加微幅呼吸與跟隨；角度只小幅震盪，不旋轉到背面。
2. **時間軸改連續橫線**：六個里程碑排在同一條由左至右的連續軌道上；進入視區後軌道填色與光點從左向右走完全程，节点依序浮現。桌機六個里程碑一次看見；手機仍是一條完整橫線，可左右滑動，不再拆成點狀卡片。
3. **移除「2003 創立年份」卡片**：下方四數字列改為三格（6 人用、9 寵物、3 品質），不再有点击后往上跳的 2003 入口。
4. **手機保留背景世界地圖、流光與貓咪**：`#globalMap` 與 `.flow` 透明度由 0.28／0.32 提高到 0.42／0.45，桌機與手機一致；`prefers-reduced-motion` 改為「靜態顯示」而非 `display:none`，避免手機因系統設定完全看不到背景。
5. **手機導覽補回**：`@media(max-width:900px)` 加入 `.nav-toggle{display:inline-flex}`；展開後品牌理念、最新消息、產品、技術、實例、商城、訂單系統、洽詢全部可點，商城與訂單系統在手機也能直達。

延續 v13 的全站導覽前綴、去浮動藍框、奔跑狗照、非綠色商城按鍵、即時 TWD／USD 換算、`checkout.html`（Visa／LINE Pay）與六題 Q&A。

## 客服機器人（預留功能）

- 收合：蹲坐吐舌拉布拉多；展開：站立搖尾；可拖曳、一鍵全螢幕／縮回，狀態記憶於 `localStorage`。
- 四個快速問題＋關鍵字回覆＋轉接真人；回覆皆為**示範文案**。串接：在 `script.js` 的 `replyChat()` 中把 `t('chat.a*')` 換成 API 呼叫，`chat.a4` 換成客服系統連結。

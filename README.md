# 精鴻生醫 v10｜品牌形象網站樣板（給老闆審閱）

以 v9 為基礎，依老闆第四輪回饋整體升級：

1. **清爽可靠配色**：全面翻為淺色玻璃系（薄荷綠＋暖陶色），放棄暗色調；topbar、nav、卡片、面板、footer 一致化。
2. **真實點陣世界地圖**：重繪 canvas 點陣密度與連線亮度，地圖清晰可見；台北出發弧線＋流動光點。
3. **滑鼠 3D 分子**：bioCanvas 分子網絡加上 pointermove 平滑插值，滑鼠移動時隨之旋轉／位移，呈現絢麗 3D 變化；流光週期放慢至 24–44s，明顯但節奏溫和。
4. **下拉小卡重設計**：改為「圖示＋標題＋深入瞭解」小卡，篩選列「全部實例」改為整條膠囊，移除零散淡色方塊。
5. **數據欄位放大**：創立年份 2003、人用 6、寵物 9、法規 3 字級放大、玻璃卡承載，hover 上浮放大 1.06 倍並強調色彩；`.stats` z-index 提高，不被跑馬燈遮蓋。
6. **Apple 級排版**：標題與內文走 SF Pro／PingFang 系統字、`text-wrap:balance`、放寬行高與字距，字級流暢縮放。
7. **狗狗照片不變形**：移除模糊背景副本，改單圖＋`aspect-ratio:1000/1603`＋`object-fit:cover`，桌機與手機皆顯示完整狗、不縮小、不糊邊。
8. **客服全面升級**：更可愛的大眼微笑拉布拉多 SVG；浮動按鈕可拖曳（記憶位置）；對話頁可一鍵全螢幕／縮回右下角，header 也可拖曳；`Esc` 關閉。
9. **多螢幕精準適配**：390–3440px、多種長寬比實測無水平溢出。

## 檔案

| 檔案 | 說明 |

| `assets/` | 本機圖片素材 |

## 客服機器人（預留功能）

- 右下角浮動全身拉布拉多形象（大眼微笑新版），漂浮＋搖尾＋耳朵抖動＋呼吸＋歪頭＋眨眼＋光暈動畫；對話視窗內亦有同款小頭像。
- 按鈕與對話標題皆可用滑鼠／觸控拖曳，位置記憶於 `localStorage`；一鍵放大全螢幕／縮回右下角；開關與全螢幕狀態記憶於 `localStorage`；`Esc` 可關閉。
- 四個快速問題：產品資訊、訂單查詢、合作洽詢、轉接真人；也可直接輸入關鍵字。
- 目前回覆為**示範文案**，已標註「未來可接入 API／客服系統」。串接方式：在 `script.js` 的 `replyChat()` 中，把 `t('chat.a*')` 換成 API 呼叫；轉真人則替換 `chat.a4` 為客服系統連結或 Webhook。
- 中英文切換時，標題、歡迎語、快速問題、示範回覆同步切換。

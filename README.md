# 精鴻生醫 v13｜品牌形象網站樣板（給老闆審閱）

依老闆第七輪回饋修正全站導覽、首頁視覺、商城／結帳流程，並新增 Q&A 專區。公開網址不變：`https://craigyu-PHD.github.io/jing-hong-biomedical-v4/`。

> v13 已於 2026-11-26 經使用者明確確認後推送並部署，線上版本即 v13。

## 本輪改造（v13）

1. **全站導覽可用**：非首頁頁面的 `#story`、`#news`、`#products`、`#craft`、`#contact` 等內部錨點統一改為 `index.html#...`；`DROP` 動態下拉也加同一前綴。商城頁點「品牌理念／品牌故事」可正確回首頁對應區塊，`#top` 仍為頁內跳轉。上方功能列結構與藍框未動。
2. **首頁視覺**：移除浮動跳動藍框（`.hero-card`）與舊直式狗狗照片；流動光帶／光暈透明度調淡（`.flow` 0.32）。
3. **時間軸改橫式**：六節點改單列橫向卡片＋軌道填色與節點進場動畫，附前後捲動按鈕與進度條；保留 `hist.y1–y6`、`hist.d1–d6` 雙語鍵。
4. **立體貓咪重繪**：改奶油／陶土／粉色的正面可愛貓臉，只做微幅 tilt／bob，不再旋轉到背面；降低流動粒子與光暈。
5. **狗狗照移位**：改用橫式奔跑照 `assets/dog-running.jpg`（Unsplash，1600×1067），放在 `#history` 時間軸下方，與品牌沿革同區，不再佔 hero 上方。
6. **商城按鍵改色**：`.sc-add` 與浮動購物車按鍵改米白／墨色漸層，不再用綠色；双幣別切換的 active 態改墨色。
7. **即時匯率**：改用免金鑰 `https://open.er-api.com/v6/latest/USD`，提供 TWD／USD 切換與四捨五入至小數點後兩位；每 30 分鐘自動更新、可手動 ↻ 更新，失敗時回退快取值或 32.92。暫不做歐元、日幣或東南亞幣別。
8. **結帳流程**：新增 `checkout.html`；購物車「前往結帳」直接導向該頁，帶入 `jh-cart`／`jh-currency`。付款預設 Visa 信用卡，另有 LINE Pay（皆為前端示範，未串金流）。
9. **Q&A 專區**：首頁新增 `#faq` 六題中英對稱常見問題（選購、幣別、付款、沿革、寵物用藥），頁尾與各分頁可連結。

延續 v12 的客服狗雙造型、單跑馬燈、暖陶 CTA、點陣世界地圖與靜態產品卡。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 首頁：主視覺、橫式沿革時間軸＋奔跑狗照、最新消息、品牌理念、雙產品線、技術品質、實例、Q&A、商城／訂單入口、洽詢 |
| `shop.html` | 購物商城：15 張靜態產品卡、即時 TWD／USD 換算、非綠色加入鍵、浮動購物車、前往結帳 |

| `assets/dog-running.jpg` | 橫式奔跑狗照（v13 新增，Unsplash） |

## 客服機器人（預留功能）

- 收合：蹲坐吐舌拉布拉多；展開：站立搖尾；可拖曳、一鍵全螢幕／縮回，狀態記憶於 `localStorage`。
- 四個快速問題＋關鍵字回覆＋轉接真人；回覆皆為**示範文案**。串接：在 `script.js` 的 `replyChat()` 中把 `t('chat.a*')` 換成 API 呼叫，`chat.a4` 換成客服系統連結。

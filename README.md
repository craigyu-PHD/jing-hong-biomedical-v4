# 精鴻生醫 v9｜品牌形象網站樣板（給老闆審閱）

以 v8 為基礎，依老闆第三輪回饋重新設計：

1. **自然下拉**：改為 hover 85ms 延遲＋220ms 關閉延遲，搭配點擊與鍵盤 focus；移除方塊＋圓點圖示，改為文字膠囊＋箭頭；下拉玻璃感更輕、不再干擾相鄰欄位。
2. **移除右上集合選單**：上方整排已是功能選單，只保留中英文切換（topbar）。
3. **最新消息標記**：跑馬燈與新聞列表改為 ✦ 星光字標，移除框框與圓點。
4. **Apple 系字型**：標題與內文改 `-apple-system / SF Pro / PingFang TC`；數字用 `tabular-nums`，玻璃卡片承載，避免遮蓋。
5. **玻璃質感**：nav、下拉、卡片、面板、註冊視窗皆採半透明毛玻璃；footer 加入斜向流光掃過動畫。
6. **全球化主視覺**：hero 背後新增點陣世界地圖＋台北出發的弧線連線與流動光點（canvas，支援 reduced-motion）。
7. **註冊防機器人**：會員登入新增「註冊新帳號」玻璃視窗，含 human checkbox、隨機數學題、honeypot 與前端驗證。
8. **照片適配**：窄直幅照片框＋`object-fit:contain`，桌機也能看到整隻狗；支援 390–1920px 無水平溢出。

| `assets/` | 本機圖片素材 |

## 客服機器人（預留功能）

- 右下角浮動全身拉布拉多形象，漂浮＋搖尾＋耳朵抖動＋呼吸＋歪頭＋眨眼＋光暈動畫；對話視窗內亦有同款小頭像。
- 點擊開啟／關閉對話視窗；開關狀態記憶於 `localStorage`；`Esc` 可關閉。
- 四個快速問題：產品資訊、訂單查詢、合作洽詢、轉接真人；也可直接輸入關鍵字。
- 目前回覆為**示範文案**，已標註「未來可接入 API／客服系統」。串接方式：在 `script.js` 的 `replyChat()` 中，把 `t('chat.a*')` 換成 API 呼叫；轉真人則替換 `chat.a4` 為客服系統連結或 Webhook。
- 中英文切換時，標題、歡迎語、快速問題、示範回覆同步切換。

# 精鴻生醫 v6｜品牌形象網站樣板（給老闆審閱）

以 v5 為基礎，參考 Dribbble「AI Healthcare Website - HealthTech Hero Section / Protera（Fulcrum Rocks）」的視覺語言：近黑 `#100D0C`、暖褐 `#554C40`、陶土 `#A75743`、鼠尾草 `#70807E`、苔綠 `#A19C65` 五色票，3D 分子結構、大膽粗體、極簡 UI、平靜自信的科學感。為避免整頁深色，改用暖白底承載這些色票。

v5 既有成果保留：緊湊間距、JH 幾何 Logo、等寬三欄頁尾、中英切換、右下角可開關的狗狗客服機器人。hero 粒子動畫升級為 3D 分子網絡（透視投影＋鍵結＋呼吸光暈）。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 首頁：主視覺、最新消息、品牌理念、雙產品線、技術品質、實例、訂單入口、洽詢 |
| `cases.html` | 實例分享（分類篩選） |
| `order.html` | 訂單系統入口（會員登入、訂單查詢、流程、服務、FAQ） |
| `style.css` | 共用樣式、RWD、客服機器人動畫 |
| `script.js` | 雙語字典（330 鍵）、篩選、表單示範、3D 分子動畫、客服機器人 |
| `assets/` | 本機圖片素材 |

## 客服機器人（預留功能）

- 右下角浮動狗狗機器人形象，漂浮＋眨眼＋光暈動畫；可愛但不干擾閱讀。
- 點擊開啟／關閉對話視窗；開關狀態記憶於 `localStorage`；`Esc` 可關閉。
- 四個快速問題：產品資訊、訂單查詢、合作洽詢、轉接真人；也可直接輸入關鍵字。
- 目前回覆為**示範文案**，已標註「未來可接入 API／客服系統」。串接方式：在 `script.js` 的 `replyChat()` 中，把 `t('chat.a*')` 換成 API 呼叫；轉真人則替換 `chat.a4` 為客服系統連結或 Webhook。
- 中英文切換時，標題、歡迎語、快速問題、示範回覆同步切換。

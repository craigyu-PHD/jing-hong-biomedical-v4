依老闆第六輪回饋，重做四項不滿意之處（v12）。公開網址不變：`https://craigyu-PHD.github.io/jing-hong-biomedical-v4/`。

## 本輪四項改造（v12）

1. **重大事件時間軸重做**：改為一列一事（左年份大字＋中軸線＋右標題說明），預設即時可見，不再因進場動畫透明而看不到；六個節點捲動時依序淡入。
2. **下拉選單精簡**：寬度 216→168px，移除方塊編號與星光圖示，只留功能名稱＋右側 `›` 按鍵提示。
3. **購物商城重做**：15 張既有產品卡改為 HTML 靜態呈現（不依賴 JS 生成），並加入 **NT$／USD 雙幣別切換**（繁中預設台幣、英文預設美金，可手動切換並記憶；示意匯率 1 USD≈32 TWD）；購物車改右下浮動抽屜，可加入、增減、篩選、結帳示範。
4. **首頁四數字精緻化**：由 286×149px 大卡改為 60px 高的細膩数据列，數字與標籤同行、分隔線區隔，hover 顯現箭頭，不再佔空間。

延續 v11 的客服狗雙造型、單跑馬燈、暖陶 CTA、世界地圖與正中間立體貓咪。

## 客服機器人（預留功能）

- 收合：蹲坐吐舌拉布拉多；展開：站立搖尾；可拖曳、一鍵全螢幕／縮回，狀態記憶於 `localStorage`。
- 四個快速問題＋關鍵字回覆＋轉接真人；回覆皆為**示範文案**。串接：在 `script.js` 的 `replyChat()` 中把 `t('chat.a*')` 換成 API 呼叫，`chat.a4` 換成客服系統連結。
